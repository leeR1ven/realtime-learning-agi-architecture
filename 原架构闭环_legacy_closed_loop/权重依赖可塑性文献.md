# 权重依赖可塑性：证据与本模型候选规则

核查日期：2026-09-06。本文只提出可检验的候选，不表示这些规则已接入模型或已经改善行为。

用户提出的“弱连接容易增强、强连接继续增强越来越难”值得实验。已有特定突触和刺激条件下的原始研究支持与初始强度有关的可塑性；“全体权重必须呈普通正态分布”则没有得到以下证据支持。应当让分布由经历和更新规则形成，观察是否保留区分和完成行为，不按目标直方图重排已学连接。

## 可核查的原始研究

1. **Bi 与 Poo，1998，培养大鼠海马神经元实验。** 配对刺激的先后顺序决定增强或减弱；明显增强主要发生于初始较弱的突触。其减弱结果没有明显的初始强度依赖。需要注意文章讨论的百分比变化：相对增强更大，不能直接翻译为“弱突触每次获得的绝对增量一定更大”。这是特定培养条件下的结果，不能直接推广到全部脑区和抑制突触。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6793365/)，[摘要与 DOI](https://pubmed.ncbi.nlm.nih.gov/9852584/)。

2. **Matsuzaki 等，2004，单个树突棘实验。** 在大鼠海马 CA1 切片上对单棘重复释放谷氨酸，小棘的扩张可持续，大型蘑菇状棘的扩张较短暂；扩张伴随该突触 AMPA 电流增加。这支持初始结构大小影响后续可塑性，不能据此断言所有小权重都应获得一次性大跳变。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4158816/)。

3. **van Rossum、Bi 与 Turrigiano，2000，计算研究。** 基于实验拟合权重依赖学习，得到稳定、单峰、右偏的权重分布。其基本模型的平均绝对增强近似为常量，减弱量正比于当前权重，并加入乘性噪声；因此“相对增强随权重变小”不等于其主要方程用了饱和上界。它说明权重依赖及增减平衡可以稳定统计分布，不能证明长期保存任意记忆或出现复杂逻辑。[全文 PDF，方法与公式在正文第 2 页](https://www.pure.ed.ac.uk/ws/portalfiles/portal/7940885/8812.full.pdf)。

4. **Song 等，2005，大鼠视觉皮层连接测量。** 对第 5 层锥体细胞进行同时膜片记录，连接强度呈明显偏斜，作者使用对数正态分布描述；少数较强连接与多数较弱连接并存。测量对象是该局部回路的兴奋连接，不是全脑全部连接的统一分布。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC1054880/)，[公开 PDF](https://www.hms.harvard.edu/bss/neuro/bornlab/nb204/papers/song-etal-plosbiol2005.pdf)。

5. **Loewenstein、Kuras 与 Rumpel，2011，小鼠在体成像与建模。** 数周跟踪听觉皮层树突棘，单神经元的棘大小分布能用对数正态描述；绝对大小波动随棘大小增加，具有乘性特征。这里测量的是兴奋突触的形态相关指标，不能把棘体积直接等同于本程序的数值权重。对数正态也不是普通正态。[全文](https://pmc.ncbi.nlm.nih.gov/articles/PMC6623170/)，[作者公开 PDF](https://loewenstein.huji.ac.il/sites/default/files/yonatanloewenstein/files/9481.full_06_2011.pdf)。

## 首先测试的工程规则

保持当前“先激活 → 后激活”的学习触发、一个共享时间序列和现有连接表，仅改变触发时对已有权重的计算。下面是工程推断，不是上面论文的原样复现。

令当前非负权重为 `w`，初始增强量为 `η`，软上界为 `W`，满足 `0 < η <= W`。先测试：

```text
Δw = η × max(0, 1 − w / W)
w_new = w + Δw
```

弱连接接近零时，每次增加约 `η`；到达 `0.5W` 时增加 `0.5η`；到达 `0.9W` 时只增加 `0.1η`。从 `w <= W` 出发不会越过上界，反复学习逐渐接近它。对已有超过新上界的连接，增强步不强行截断记忆，而让原有衰减处理；加载旧模型时必须明确保留这一行为。

这个函数不新增每条边的计数、资格迹或额外记忆，也不区分目标类别。它不保证短期就学会：绝对初增 `η` 仍需与汇入同一细胞的活跃边数、门槛、抑制和去抑制共同校准。程序报告的总兴奋电流峰值不能当作单条边的权重上界。

降低先保留现有乘性维护：

```text
每到原有维护时刻：w_new = d × w，0 < d <= 1
```

它不增加学习状态，暂不剪枝时保留同一表中权重之间的比例。`d`、维护间隔和删除阈值要一起看；单次记忆如果不再强化，长期仍会衰减到无法读取。现有“连接达到警戒线才开始衰减”的启动条件也会改变训练早期与后期的有效学习平衡，实验必须记录实际维护次数。

一个后续候选是 `w_new = w / (1 + λw)`：强连接每次下降得更多，弱连接损失更小。但它会改变相对强度、可能削弱已经学熟的有用连接；目前没有理由同时替换增强和降低两个环节，先与已有乘性降低比较更容易判断原因。该候选是工程方案，不能称为已验证的大脑法则。

如果将有界增强和连续小比例降低近似写为 `dw/dt = fη(1−w/W) − λw`，其中 `f` 是这条边被强化的频率，则近似平衡值为 `fη / (λ + fη/W)`。这说明不同经历频率仍可形成不同强度，同时高频连接逐渐饱和。它既不保证正态，也不保证对数正态；实际模型有离散维护、剪枝和活动反馈，必须实测。

## 判定是否值得采用

先在前额叶可学习连接上比较原规则与候选，再决定是否适用于按时间记录的感觉和运动记忆。不同试验从同一完整生活存档克隆，保留同一时序记忆结构；克隆只是实验对照，不是把运行模型的记忆分区。

观察旧经历是否还能调用、新联想建立需要多少实际经验、相反情境下能否改变实际选择，以及权重上界附近的比例、活动规模与抑制强度。单条边有上界仍不能保证总电流有界于可用范围，因为活跃汇入边数也可能增长。

允许 `声音 → 色标 → 路线` 逐渐缩短为直接调用路线，也允许部分线索触发完整记忆。不能把不再显示色标或不再严格满足人工 AND 真值表直接判为失败。是否学到了有用捷径，要由实际路线、目标完成与条件改变后的行为检验。分布好看、活动稳定或这些局部生理相似性，均不等于实现 AGI。
