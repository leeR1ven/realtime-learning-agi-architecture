## 旧三节身体的确定问题

1. **关节力矩坐标混用（身体.py:132、317）。** 用独立动能定义重建的矩阵，和 `质量矩阵(q)` 最大差为 `8.88e-16`；所以该矩阵原本就是绝对角坐标的对称质量矩阵，`递推()` 实际给的是绝对角广义力。再次乘 `G` 后矩阵非对称（本样例差 `1.67192`）。现有站立方程实际把关节扭矩当成绝对广义力，空中方程也同样混用。直接验证：悬空时施加内部膝关节力矩 `10 N·m`，绕质心角动量竟以 `10.0000000004 N·m` 改变；真实内部力矩不应改变整体角动量。

2. **外推的 `0.5` 不是正确物理修复（身体.py:127）。** 由躯干质心位置对三个绝对角求导得到，直立时 1 N 水平力的正确广义力应为 `[0.40,0.42,0.36] N·m`；现实现得到 `[0.59,0.39,0.18]`。因此不能把标注的冲量当成已可靠实现的躯干外力。用某个总角动量指标反调比例，不能替代逐自由度虚功一致性。

3. **起跳直接注入速度和能量（身体.py:267）。** 静止身体调用 `起跳(身体,1.8)`，立即增加竖直动量 `34.2 kg·m/s` 和动能 `30.78 J`，没有经过肌肉做功与地面反力。水平分量还由倾倒速度估算并限幅；它不是从接触解除继承的真实基座速度。

4. **旧迈步只改观测支点（身体.py:209）。** `迈步(身体,0.5)` 后，报告脚 x 为 0.5 m，实际链基座仍为 0 m。它会改变感官中的相对脚位置，却未改变物理链。当前跳步验证走的是另一个函数，但该 API 仍不能用作运动能力证明。

5. **神经池未成为实际控制路径（感官本能.py:140-178）。** 本能直接读连续状态并计算 PD；温度计档数仅作为返回值生成，实际关节扭矩来自连续 `目标`，没有经过 `感官池 -> 固定神经连接 -> 运动池解码`。文件中也没有可塑连接的学习更新。

6. **验证标准过弱（验证.py:65、91、116）。** 推力和跳步扫描函数无论结果都返回 True；空中不检查摔倒或其他身体部位触地。地面没有完整单边接触/摩擦/脚支持多边形约束，所以“未触发摔倒阈值”只说明这段简化控制循环继续运行。三个 1 秒快照都未倒，且位移全为 0 m，这不证明持续自主移动。

现有代码里值得保留的是三节链运动学、独立动能计算和使用接触冲量方程实现的基点非弹性落地形式；落地检查仍需与正确力矩坐标、真实接触释放及更完整碰撞结合。

正确的固定基点动力学形式应为 `M(q) qdd = G @ joint_torque + Q_damping + J_torso.T @ force - h(q,qd)`。自由链同样先把内部关节力矩转换为绝对角广义力；自由飞行中基端关节不能凭空获得外部扭矩。修正后原有 PD 参数的成功率不能直接继承。

## 新的最小闭环物理底座

按主任务安排创建 `F:\一种AGI架构\闭环仿真\world.py`，保留旧身体文件供后续修复。新世界明确是俯视二维圆形推进身体，并非双足行走模型。

- 动作只接收四个 0..1 肌肉激活量：左前推、左后推、右前推、右后推。肌肉经过 40 ms 一阶滞后产生左右牛顿力及力矩，动量积分产生位移和转向。环境提供平动/转动阻尼；不以动作直接设置速度、位置或朝向。
- 碰撞使用圆与矩形的单边不穿透约束、法向反冲量与库仑摩擦。触觉来自接触法线，痛觉来自真实反冲量。物理子步默认 5 ms，并随高速自动细分防止穿过薄墙。
- 五条真实射线给出距离和 RGB，近处墙会遮住彩色圆。圆只是视觉物体，不向行为模型暴露目标动作或自动追逐策略。
- 可替换起始位置、朝向、墙和视觉物体，便于使用未训练的布局验证。世界本身没有感官到动作的行为分支。

`check_world.py` 的 11 组独立检查全部通过：牛顿力解析加速、纯力偶解析加速、左右对称、拮抗肌抵消、阻尼耗能、100 m/s 撞 1 cm 薄墙不穿透、持续顶墙反馈、摩擦碰撞不增能、射线几何和遮挡、非法输入与初始重叠拒绝、10 秒随机动作确定性重放。详见 `world_checks.json`。

限制：这是可信但刻意很小的物理任务平台；还未模拟腿、重力步态、肌肉代谢、视觉图像或真实语言理解。检查通过证明底层因果和数值约束成立；闭环神经控制、赫布在线学习和迁移效果需由主集成任务另外给出学习开/关、洗牌及留出场景对照。
