# 本轮自主推进：从连续关联到可检验的行动与交流

用户授权在不反复确认的情况下实施、调参、检查并修正问题，以 AGI 为远期目标。AGI 成功没有可承诺的配方；本轮只把可复查的实际结果写为已完成能力。

## 约束

- 每个运行个体只有一个共享时间轴，感觉、动作和奖励经历不按任务拆分。
- 实际感觉先入脑；地图坐标、目标标签、最短路线和教师动作不入脑。
- 前额叶保持参与；消融在冻结的完整实验副本进行。
- 用户现有完整生活保留。新机制先作为有明确标识的候选实验；未经等价性验证不冒充原架构自然涌现，也不覆盖运行中的生活。
- 新增工程机制、出生运动协调与真正学习出来的连接分别记录。

## 先分析

1. 检查原版声音→同时间多感觉→前额叶→动作路径与失败原因。
2. 核查固定目标路线经验是否存在，区分感觉配对与实际寻路训练。
3. 测试不同容量下的上下文联想、稀疏经验遗忘与外驱覆盖。
4. 检查连续学习的时间环回绕、保存恢复与资源边界。

## 实施顺序

1. 固定目标的自主探索实验；仅由实际连续经历形成感觉/动作/后继联系。
2. 候选前额叶扩展：感觉簇分化、目标回忆、沿学习连接传播以及当前情境对动作的共同选择。若改变原放电/学习方程，明确说明并做消融。
3. 学过局部路线后测试未练过的起点/目标组合，以及途中目标改变和实际道路阻塞。使用独立评分，不把走动或神经元活跃算作导航成功。
4. 加入连续参数发声器、真实 PCM 自听和动作—声音学习；再测试听到声音后的模仿。模仿声学片段不等于自然语言理解。
5. 检查保存恢复、无特权输入、单时间连续性、旧数据保护、随机种子差异与运行速度；失败后修正并复查。

## 初始发现

- 默认生活只有 544.8 秒，其中此前 3600 次控制调用实际贴墙。
- 旧配对色标随身体位置移动，不能当作固定地点的路线经验。
- 当前前额叶 `.9/25` 衰减对低频经验过快；完整时间记忆仍保存，不代表前额叶关系没有遗忘。
- 当前没有发声执行器。固定前处理与循环前额叶容量需要分别考虑。

后续实际完成项、失败项与证据写入 `自主推进结果.md`，不以计划替代结果。
