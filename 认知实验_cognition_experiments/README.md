# 前额叶与持续认知实验

目标是检验前额叶的内部活动如何保持上下文、结合当前输入并改变决策，为虚拟环境中的持续学习与交流建立证据。避障、行走和音调配对是基础接口实验，不能作为复杂认知或 AGI 的验收。

## 已有原型的因果检查

运行 `audit_existing_pfc.py`，读取现有 `demo_brain.npz` 的独立副本，不改原网络或存档。对静音和四种音调分别设置十种不同前额叶持续活动：全静息、全激活和八种随机稀疏活动。固定权重、身体观察、感觉痕迹、动作状态和海马记忆，只干预 `previous` 与 `pfc.念头`。

本次 50 次干预的动作评分和肌肉输出全部一致。另测得 `pfc_enabled=False` 时持续状态仍然更新；这个开关还同时关闭直接听觉关联，因此不是选择性工作记忆消融。

证据：[existing_pfc_audit.json](F:/一种AGI架构/认知实验_cognition_experiments/results/existing_pfc_audit.json)。报告包含受检代码和存档的 SHA-256。

原因可从 [brain.py](F:/一种AGI架构/闭环仿真_closed_loop_sim/brain.py:202) 直接追踪：内部 `thought` 会更新，而动作中的前额投票来自 `pfc.驱动(cue)`。所以现有原型证明了学得的前额连接能做线索关联检索，尚未证明持续前额状态参与上下文决策。这不否定用户完整的架构设想，也不意味着所有前额叶连接均与行为无关。

## 新候选机制的边界

`pfc_probe.py` 是独立诊断实验，尚未替换或接入原有仿真。固定随机稀疏输入／循环连接、泄漏膜状态、tanh 非线性率近似，以及局部输出学习，属于显式新增的候选机制。它不是对 `前额叶联想区` 的直接扩容，也不能用成绩证明原有时序赫布与抑制规则已经实现同样功能。

候选网络只有当前输入和自身神经状态；不读规则编号、标准答案、试次编号或符号历史缓存。二选一响应提交以后，环境才提供教师响应进行局部学习。这个接口提供了明确答案监督，不能称作已经从自然语言或单一奖惩中自主发现规则。

主任务：上下文 A/B → 延迟与无关干扰 → 查询 X/Y。四种组合的左右答案均衡；同一查询在两种上下文下答案相反。标准答案的条件逻辑只能写在环境评分与反馈端，不能作为模型特征。训练中出现全部四种组合，因此测试成绩只说明延迟条件判断，不能称为陌生组合泛化、语言理解或复杂逻辑。

对照包括：不同前额叶宽度、决策前清除状态、单独训练的每帧清状态模型、打乱反馈模型、当前查询即可解答的简单任务。另列纯相关 Hebb 与含输出误差的 delta 读出；两者不同，不能混称为同一个学习规则。清状态导致失败本身仅表示该模型使用了持续状态；还需独立训练的无记忆对照和输入审查来排除人为制造的必要性。

## 2026-09-06 实际结果

固定参数，3 个出生种子（3、11、29），每个独立模型接受 1200 次在线教学，每项每种子测试 240 次。首次运行耗时 12.12 秒。没有为分数调整参数。

| 条件（三种子平均） | 64 单元 | 256 单元 | 1024 单元 |
| --- | ---: | ---: | ---: |
| Delta 读出，严格未见的完整序列配对 | 83.06% | 99.86% | 100% |
| 已学 Delta 网络，查询前清除上下文 | 50% | 50% | 50% |
| 同容量、每帧清状态的独立学习模型 | 50% | 50% | 50% |
| 同容量、打乱教学反馈的独立学习模型 | 50% | 50% | 50% |
| 当前查询即可解答的简单任务 | 100% | 100% | 100% |
| Delta 读出，未训练的 8–12 帧延迟 | 52.22% | 84.17% | 79.72% |

256 单元的纯相关 Hebb 读出，在严格配对测试中平均为 **56.94%**。这里的相关规则使用有正负值的率活动和通用归一化，也不等同于原有布尔时序 Hebb／去抑制完整网络。因此不能将 Delta 的高分当成原规则的成绩，也不能用这个 Hebb 对照的低分否定全部 Hebb 架构。

扩大到 256 单元在这项短上下文诊断上有收益；扩大到 1024 单元的长延迟成绩没有继续上升。宽度改变时随机连接、特征多样性和读出参数量也一起改变，不能只归因于神经元数量。长延迟是离散实验步数，未接仿真时钟，不能直接换算成真实工作记忆秒数。

独立审查发现首次 IID 测试中，每种子 240 条完整序列分别有 131、128、134 条曾在训练出现。首次结果保留在 [pfc_probe_quick.json](F:/一种AGI架构/认知实验_cognition_experiments/results/pfc_probe_quick.json)。上表的严格配对成绩来自新增的 [pfc_probe_quick_strict.json](F:/一种AGI架构/认知实验_cognition_experiments/results/pfc_probe_quick_strict.json)：直接加载原存档、不重训，每种子 120 对完整序列与训练零重合。同一对的查询和干扰序列完全一致，仅早期上下文不同。过滤重复会让测试偏向更长的序列，因而它与首次 IID 测试的分布不同。

[独立审计](F:/一种AGI架构/认知实验_cognition_experiments/results/independent_probe_audit.json) 使用另一组零重合配对，再次测得 256／1024 单元各三个种子均为 100%，清状态均为 50%；每帧清状态的模型也能学会即时任务，正确率 100%。审计核验了感官输入中没有标准答案、决策后才反馈、测试不更新权重，以及成对试次的完整后缀逐值相同。

12 套候选存档的固定连接、读出权重、膜状态及继续学习结果均逐值一致。存档支持本实验的状态恢复，尚未实现与原闭环存档的融合兼容。

## 真正需要推进的任务

1. **上下文决策与负荷**：由二值诊断扩展到多规则、多个需保持的对象、延迟与干扰曲线。区分容量增加、连接结构变化和训练数据增加的作用。
2. **交流中学习**：人在虚拟环境里给陌生物体起名字，教授关系并纠正错误；测试首次作答、指代、未教过的组合和知识迁移。出生连接不能包含具体词义和任务答案。
3. **内部推演与纠错**：让前额叶产生的预测影响选择，再由真实结果检验预测。内部想象不能被直接写成已发生的经历。
4. **持续知识与融合**：学习新任务后复测旧任务；让不同分支的知识共同参与新任务，记录冲突、遗忘和融合代价。

不要求小模型先具备所有复杂能力再扩容；应随任务负荷一起扩大，观察是否出现可重复的收益。本诊断若已被小网络解决，就不能用于声称更大前额叶没有价值，也不足以决定大规模租卡配置。

```powershell

```

## 研究依据

前额叶的混合选择性研究显示，神经元对多个任务因素的非线性组合响应与可读出的行为功能有关：[Rigotti 等，Nature 2013](https://www.nature.com/articles/nature12160)。上下文依赖的感觉决策也有前额叶群体循环动力学的实验与建模研究：[Mante 等，Nature 2013](https://www.nature.com/articles/nature12742)。这些研究支持检验混合表征和循环状态的方向，不是对当前代码、具体学习规则或仿脑 AGI 可行性的证明。
