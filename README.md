# 一种可实时学习的 AGI 架构（关联神经元架构 · Relational Neuron Brain）

纯神经元连接的仿脑持续认知模型原型。目标是让一个“数字大脑”只靠**神经元之间的连接与放电**完成感知、记忆、联想、运动控制与学习，不依赖查表、搜索或传统梯度训练等代码捷径。

所有核心代码为 Python + NumPy，运行在 CPU 上；代码用中文命名，根目录文件名与一级文件夹名采用中英双语。

---

## 这个项目想验证什么

- 大脑不是一个“输入→隐藏→输出”的黑盒，而是多个脑区并行、互连、持续运行的闭环；
- 记忆不是存快照，而是**连接权重**随时间、随放电序列生长；
- “想”和“回忆”都只是神经元放电沿既有连接传播；
- 从外到内的感知网络和从内到外的运动/想象网络方向相反，需要专门的反向通路。

## 核心设计要点

下面是这套架构最重要的 8 条机制，按“是什么 / 怎么工作 / 解决什么问题”展开；想再深入可以看 [架构说明.md](架构说明.md) / [ARCHITECTURE.md](ARCHITECTURE.md)。

1. **成对特征神经元（Paired feature neurons）** —— 每个特征用**正、反两个神经元**表示，二者竞争、每对**恰好激活一个**。外部信号先写进池子的 `信号` 数组，`更新所有对()` 时正信号≥反信号则正神经元亮、否则反神经元亮，然后清空信号等待下一帧。这样“每对恰一、整体约一半”由竞争自动保证，不需要任何外部规则；再把一个特征拆成 `每档对数` 对，就成了 0~N 级“档位温度计”，可以表达亮度、响度、肌肉发力这类强弱（实现见各文件里的 `特征神经元池`）。

2. **稀疏局部连接神经网络（Sparse local networks）** —— 处理信号的网络每层宽度和输入层相同，每个神经元只连上一层**环形邻域**（默认 ±10，首尾相接），权重出生时在 `[0, 权重范围)` 里随机取定后**永远不变**，靠阈值放电（加权和 ≥ 阈值才亮）。这类网络是“信号处理电路”，**不做赫布学习**，所以快、稳、可预测。层数、连接半径、权重范围、阈值初值都在各文件顶部“全局创建”区块一次改完，下游所有宽度自动跟随。

3. **时序赫布学习（Temporal Hebbian learning）** —— 赫布定律的“时序版”：**上一帧先放电**的神经元与**下一帧后放电**的神经元之间，连接增强一次（方向：上帧→下帧）。同帧同时亮的不学，避免把“同时发生”误当成“先后发生”。反复出现的先后顺序会变成一条**可回放的记忆链**：A 帧过后，A→B 连接让“下一个轮到 B”更容易发生。三个记忆区和前额叶联想区都靠它长连接。

4. **海马体时间环（Hippocampal time ring）** —— 全系统共享一条时间线：172.8 万个时间神经元首尾相连绕成一圈（像手串的珠子），每个占 0.05 秒；外界一帧 = 0.1 秒 = **连续点亮 2 个**；绕一整圈正好 24 小时。做成环是为了循环复用时间槽，不随运行无限新增；帧与帧之间用 2 个连续时间神经元承接，保证不漏帧、不串帧。记忆事件挂到“当时”的时间神经元上，回忆时就能沿时间顺序回放。

5. **抑制 / 去抑制神经元（Dynamic inhibition）** —— 前额叶里同时有普通念头神经元、抑制神经元（压制附近正常神经元）和去抑制神经元（压制抑制神经元，等于“解除压制”）。动态规则是：亮的念头**太多**就当场加强整体抑制，只保留信号最强的一批；**太少**就放松抑制，把确有信号的细胞也点亮。目标区间跟随“典型念头”大小自动伸缩（约 0.5~1.3 倍），让思考时始终**有念头、但不多不少**——既不会一次点亮几千个乱成一锅，也不会一个都叫不醒。

6. **天生互惠返回线（Innate reciprocal return lines / mirror network）** —— 感知是“外→内”，而想象、回忆是“内→外”，方向相反。为此前额叶到各感觉区在出生时按**固定镜像关系**铺好一条返回通路：把前额叶的输出沿正向网络的连接逐层回传，`返回保留比例`（默认 0.3）决定保留多少。这条线**不学习、不遗忘**，让模型“想到 X”时能反向激活“看到/听到 X”时会亮的神经元，等于天生的互惠布线。

7. **运动反向网络（Motor reverse-Hebbian network）** —— 运动是大脑向外发命令（“命令码 → 肌肉”），一开始没有任何现成参数能走这个反向。办法是让模型像婴儿一样**随机乱动**：观察每一帧命令码亮起的输出神经元与当时激活的肌肉特征，在反向表里把“命令 → 肌肉”连接加 1；`一次学会=True` 时同一连接见过一次就饱和为 1。学过的路**单调保留、绝不遗忘**；反复做同类动作有门控、不再新增连接；没学过的全新命令码则靠“天生镜像底版”给出肌肉的大致位置。

8. **权重连接管理（Weight manager）** —— 赫布学习只会“加”不会“减”，没有管理的话记忆连接会无限膨胀。`连接表` 在条数到达 `警戒线`（默认 10 万）后定期整体衰减：所有权重 × `衰减率`（0.9），低于 `消失下限`（0.05）的连接删除。常用连接虽然也被衰减，但每次使用会加回（强化量 1），停在平衡值附近；少用的连接反复衰减最终归零消失——记忆自动“删繁就简”，连接数被长期压住。

## 运行环境

- Python 3.x + NumPy（项目自带虚拟环境在 `.venv/`，未入库）。
- 主要依赖只有 NumPy；可视化闭环使用 Tkinter（Python 自带）。

```powershell
# 核心文件自检（在 F:\一种AGI架构 下）
.\.venv\Scripts\python.exe -X utf8 视觉前处理_visual_preprocess.py
.\.venv\Scripts\python.exe -X utf8 前额叶区_prefrontal.py
.\.venv\Scripts\python.exe -X utf8 运动输出区_motor_output.py

# 可视化闭环仿真（会弹出窗口，身体自动活动并学习）
Set-Location -LiteralPath '闭环仿真_closed_loop_sim'
& '..\.venv\Scripts\python.exe' -X utf8 viewer.py

# 无窗口冒烟/完整评估（19 项检查 + 10000 帧压测）
& '..\.venv\Scripts\python.exe' -X utf8 viewer.py --smoke-test
& '..\.venv\Scripts\python.exe' -X utf8 evaluate.py --soak-frames 10000
```

## 当前验证结果（节选）

- 闭环仿真 `evaluate.py` 19/19 项检查通过：碰撞学习迁移、任意声音-动作配对、出生本能（接触退缩/疼痛哭喊）、分支记忆融合、存档恢复一致性、运动反向连接可致动。
- 10000 帧（模拟 1000 秒）压测：平均约 16 ms/帧、95% 分位约 22 ms、最慢 54 ms，无超 100 ms 帧，可维持实时运行。
- 前额叶：真实经历回放 100% 覆盖下一个念头；动态抑制把活动容量稳定在“典型念头”大小附近。

## 已验证与仍待解决的问题（诚实声明）

已验证（闭环内）：感知 → 前额叶 → 动作 → 反馈 端到端可运行；在线学习确实改变行为；前额叶对决策有因果路径；互补记忆的多分支融合可用；运动依赖学到的反向连接。

仍在努力解决的开放问题（也是很好的贡献切入点）：

1. **长期运行下的记忆增长** —— 时间记忆连接仍随时间增加（10000 帧约 37.5 万条）；衰减机制能兜底，但稳态行为还需要更长的压测和更聪明的遗忘策略。
2. **无锚点的联想漂移** —— 自由回忆会像走神一样漂移；沿真实闭环回放则不漂移。如何用注意/门控控制漂移仍是开放问题。
3. **规模扩展** —— 目前全部跑在 CPU + NumPy 上；10~100 倍规模的性能剖析、GPU 或稀疏后端都还没有探索。
4. **冲突经验与巩固** —— 互补记忆的两个分支能干净融合；冲突教学和类睡眠式的记忆巩固还没研究。
5. **更丰富的身体** —— 目前是二维推进身体；更多传感器（仿真里已有触痛觉）、第一人称 3D 环境和更多执行器是下一步。

## 如何参与贡献

任何人都欢迎。最快的帮法：

- **阅读并批评**：任何看起来不对的地方（命名、数学、生物学或工程）都欢迎开 Issue。
- **跑压测**：在你自己的机器上运行压测，报告每帧耗时和记忆增长数据。
- **挑一个上面的开放问题**：设计一个小消融实验，放进新的实验文件夹（参考 `认知实验_cognition_experiments/` 的规范：写清楚相对原始规则的改动、测量因果效应、不夸大结论）。
- **翻译或完善文档**：中文为主、英文并存；中文命名还需要友好的术语对照表和示意图。

请保留至今形成的协作习惯：

1. **一次只改一个模块**，方便逐区消融对照。
2. 固定信号处理网络必须保持固定；赫布学习只动 `权重连接管理_weight_manager.py` 列出的可塑连接。
3. 优先用纯神经元/连接机制，不要用查表或代码捷径——这正是本架构的意义。
4. 依赖保持最少（核心只用 NumPy；仿真窗口用 Tkinter）。
5. 改哪个文件就补哪个文件的自检；动了闭环就在 `闭环仿真_closed_loop_sim/evaluate.py` 里加或扩展对应检查。
