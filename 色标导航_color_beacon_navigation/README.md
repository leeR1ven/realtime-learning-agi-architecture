这是一个**先听短音、随后保持上下文，自主寻找指定色标**的具身实验。当前重点是检验记忆的连续性与先后依赖：先前经历是否影响后来如何行动，回忆能否把相关经历接起来，并对真实动作产生作用。路线由模型在环境中探索；本轮不提供教师路线，只在第一次实际到达目标时给一次 `+1`。

已完成的纯自主实验见 [验收结果.md](F:/一种AGI架构/色标导航_color_beacon_navigation/验收结果.md)：部分红色路线有学习收益，但同起点总体仍为1/3，关闭顺序通路反而为2/3，尚未通过稳定导航与先后依赖的能力验收。保存了连续经历、存在前后连接，也不自动等于理解“必须先完成某一步，后一步才能成功”。

窗口默认没有人工示范。点击“开始”，或选择一个音调开始新回合。每个回合的声音只持续 **0.6 秒**，之后输入静音，脑需要依靠自身保持的活动继续行动。音调按钮从相同起始姿态重新开始任务；“换一个起点”使用环境预设的合法起点，保留学习结果，清除短时活动并重新播放本回合短音。

界面显示实际身体、墙、三个色标、31 束感官射线、轨迹、声音活动、PFC 混合细胞活动、回忆事件以及四肌肉电流。目标颜色和轨迹由环境提供给界面与评分器，未传入脑。达到目标判定范围后，已执行的动作获得一次真实奖励，窗口随后暂停，方便检查并开始新任务。身体可能先经过错误色标，因此还要看“错误色标进入”和“首先到达的色标”等指标，不能只看是否曾到过目标。

W/A/S/D 与空格保留为可选的人类肌肉示范接口，只有按住时才生效。此时模型先产生自己的预测，再记录人提供的肌肉动作，环境实际执行人工动作，界面分别显示预测和实际施力。观察本轮纯自主能力时不使用这些键；含人工示范的回合会显示人工帧数，并在到达记录中标明。声音目前通过模拟 PCM 输入，窗口未连接真实麦克风或扬声器。

当前控制器是对原固定受体、局部 Hebb、时间记忆与多簇联想思想的一次具体实验实现，没有直接用旧前额叶类取得这些导航成绩。旧“闭环仿真”中的物理身体被复用；原有 GUI 和项目根目录神经文件保持原样。

**环境与脑之间的边界。** `BeaconNavigationEnv.sensor_packet()` 只返回受限感官包。脑接收的内容是：

- 31 束距离与 31×3 RGB；这是射线受体值，尚不是从摄像头像素学出来的视觉表征。
- 身体坐标系中的前向/侧向速度、角速度、疼痛与接触。
- 8 kHz 单声道 PCM。三个目标使用不同频率的短音，默认是 220、440、660 Hz；声音不携带空间方向。

脑不接收目标编号、目标坐标、自己的世界位置或绝对朝向、地图、对象名称、教师路线、离目标还有多远。环境能读取这些量来绘图和评分；更换任务目标不会改变色标本身的视觉外观。

真实控制顺序为：`sensor_packet → observe_then_act → 四肌肉 → env.step → 环境评分`。只有当物理推进后第一次进入本回合目标的判定半径，调用方才执行 `controller.receive_reward(1.0)`，并且每回合只发一次。没有接近目标的距离奖励、没有分段路线奖励，也不为发奖额外生成一个尚未执行的动作。这个 `+1` 是环境给出的结果反馈，不是脑自己知道目标位置。

**当前记忆和行动链条。**

1. 声音激活四个频带中的相应保持单元。固定自反馈让过阈值的声音活动在静音后继续存在，新声音或回合重置会切换/清除上下文。这是当前固定的保持机制，尚未学会任意长度、任意内容的工作记忆。
2. 距离、颜色和身体信号经过成对受体量化。默认 4096 个混合细胞，每个固定随机接收一个听觉保持单元和两个感觉受体，三路信号同时越过阈值时放电。没有按“某音调对应某颜色”的答案预先布线。
3. 每帧活动、感觉和该帧肌肉电流绑定到一个时间事件。事件保存 `previous/next` 前后连接、上下文及发生帧，形成经历顺序。自主事件初始的动作读出强度为零，避免把任意探索动作立即当成正确动作；之后的真实到达奖励才能增强对应经历。
4. 当前活动沿特征到时间的连接唤起多个已增强事件，时间事件返回肌肉电流与当时的感觉。多个候选按活动和强度混合，产生连续的四肌肉输出，而非把一个色标标签直接转换成坐标或路线。
5. 回忆出的感觉再次经过相同出生受体/混合投射，形成第二路 PFC 活动。它可以支持当前候选；上一帧被回忆的事件，其 `next` 事件也能对本帧选择提供小幅顺序支持。因此当前程序确实有“感觉→记忆→回忆感觉→PFC→记忆”及回忆先后连接的返回路径。

这些返回路径受到明确限制：它们只能支持本帧真实感觉已经支持的候选，不能单靠回放让身体沿一条未核对现实的路线执行。顺序支持和回忆反馈目前都是弱偏置，尚未表示“这个地点是完成目标前必须先到的子目标”，也没有进行多步预测搜索。关闭 `sequence_enabled` 或 `recall_feedback_enabled` 的对照，才有助于判断这些路径是否真正改善当前行为；仅显示它们有活动还不够。

控制器同时有出生探索与身体退缩本能：随机选择若干基本肌肉组合持续一小段时间，在接触、疼痛或非常近的障碍下后退/转向，并保留少量继续探索。它们不读取目标颜色或地图，但确实给了身体移动和脱困能力，不能把所有运动或绕墙表现都算成后天学到的能力。联想输出仍直接产生连续四肌肉值，界面中的“前进/转向”只是将输出与出生模板比较后的诊断名称。

**奖励回溯的实现限制。** 当前默认最多保留 **4096 帧**的最近真实经历来接收到达奖励，并按每帧 `0.9995` 的系数让更早经历获得较小增强。回合重置或声音上下文变化会切断这条奖励链，防止本回合结果增强上一任务的经历。

这个 4096 帧上限是本次实现的有界存储与信用分配近似，**不是用户架构的原理**。它与默认 4096 个混合神经元是两个独立参数。短于窗口的回合可能几乎整段经历都被增强，这不能证明每一步对结果都有因果必要性；一次碰巧成功的游走也可能把无关绕路一起增强，窗口之外真正必要的早期经历则可能没有得到信用。时间顺序连接只说明“先后发生”，还不能代替对依赖关系的学习。

当前事件存储也有容量上限。实现优先复用未增强的槽位，保留已增强经历；容量全被已增强事件占满时，会跳过新的未确认经历并记录计数。槽位复用、奖励回溯边界、错误信用分配和连续记忆中断，都需要继续检查，不能以一次到达测试视为已经解决。

**自主实验与证据。** 一个完整自主实验示例：

```powershell
Set-Location -LiteralPath 'F:\一种AGI架构\色标导航'
& '..\.venv\Scripts\python.exe' -X utf8 autonomous_experiment.py --episodes 12 --steps 900 --seed 2026 --width 4096
```

`episodes` 是自主生活回合数，`steps` 是每回合上限，每步仿真时间 0.1 秒；到达目标会提前结束本回合。脚本不导入教师或路线规划器，失败回合也保留。它会比较新生模型与已有经历的模型，检查改变起始姿态后的表现，并分别切断声音上下文、视觉/身体输入、记忆到肌肉、事件顺序、回忆感觉反馈。

评估中会对独立快照显式冻结新增学习，以区分“已有经历有效”与“现场又碰巧学到”。这是诊断干预；日常自主生活和窗口中的感知、行动、记录、奖励更新仍在同一循环中运行。

从本轮中间存档继续自主生活：

```powershell
& '..\.venv\Scripts\python.exe' -X utf8 autonomous_experiment.py --resume results/autonomous_evaluation.npz --episodes 12 --steps 900 --output results/autonomous_continued.json
```

注意：当前命令行每次运行会从相同的环境探索种子序列开始；`--resume` 继续的是神经状态与经验，不保证每回合外界条件都是新样本。重复运行不能当作独立实验。窗口中的后续运行继续其随机状态，更适合交互观察持续生活。

**窗口存档。** 启动依次尝试加载 `results\living_navigation.npz`、`results\navigation_brain.npz`，都不可用时创建出生自主模型。前者是你在窗口里继续生活的模型；后者是正式自主脚本最后导出的模型。

窗口手动保存、每 5 分钟自动保存及正常退出只写 `living_navigation.npz`，不覆盖正式实验模型。新一轮实验更新 `navigation_brain.npz` 后，已有生活存档仍然优先加载；需要改看新实验模型时，先关闭窗口，把生活存档另存备份名称，再启动。脑存档包含固定连接、时间经历、强度与所需短时状态，不包含完整世界的位置和物理进度。窗口开始新场景时会清除活动状态，继续保留学过的经历。导航控制器的跨分支融合尚未在此目录验收。

下一步仍应围绕连续记忆本身：先依据实际失败定位是哪一段依赖丢失，检验切断或重排经历链是否改变后续选择，再研究如何把结果信用给到真正必要的前置经历，以及如何用回忆预测尚未出现的中间状态。扩大网络可以增加可用表征和存储容量，但不能自动替代这些机制与行为验证。
