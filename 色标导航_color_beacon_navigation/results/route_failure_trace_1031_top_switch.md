# 1031 号失败轨迹：声音记住了，回忆接到了错误阶段

这次失败的具体链条是：新 bottom 音正确替换了 top 规则；身体仍在上侧，灰墙感觉却激活了下侧或墙右侧的 bottom 经历；真实的先后连接继续推动这些经历，最终在 **25.43 秒穿过上口**。98.54 秒虽然到达同一红色目标，路线要求仍未满足。

仅重放这一个正式失败分支，共 986 帧、约 11.47 秒。完整逐帧轨迹、通道事件和首次到达记录与正式实验逐值相同；固定连接、经历、权重和原存档均未改变。完整证据在 [连接与活动 JSON](route_failure_trace_1031_top_switch.json)，事件坐标仅用于事后注释，没有输入脑。

下面帧号从 0 开始，时间是该帧动作执行前的时刻。训练回合编号也从 0 开始。

1. **9.9 秒，帧 99：仍按旧规则活动。** 身体在 `(3.99, 7.28)`，上侧规则群为 `[2]`。事件 `23952` 的权重为 1，输出两侧前进肌肉 `[0.6, 0, 0.6, 0]`；它来自 top 训练回合 19。

2. **10.0 秒，帧 100：新声音已正确生效。** 目标群保持 `[0]`，规则群变成 bottom 的 `[1]`；活动 PFC 从 215 个变成 235 个，新旧交集为 0，旧回放前沿从 1 个事件清为空。随后召回的 16 个事件全属于 bottom 语境。六个记忆提供左转、三个提供右转，转向贡献抵消约 67.8%，但合成电流仍为 `[0.2797, 0.1439, 0.3345, 0.0890]`，并非完全不动。这个局部冲突不能解释整个失败。

3. **10.6 秒，帧 106：上边界激活了下边界的经历。** 当前身体在 `(3.81, 7.80)`，唯一回忆 `16415` 却来自 bottom 回合 14 的 `(1.26, 0.23)`，当时朝向与当前相差约 178.6°。两者归一化感觉向量 RMS 差只有 `0.0226`，RGB 差为 0。这是灰墙感觉混淆的直接例子。此帧实际动作由身体反射接管，向后退。

4. **12.0 秒，帧 120：回忆与实际动作需要分开看。** 五个被选记忆全部提供右转电流，合成转向为 `−0.6`；实际肌肉却是身体反射的左转 `[0, 0.3, 0.3, 0]`，转向为 `+0.6`。新提示后的前 30 帧中，19 帧由身体反射控制，7 帧由探索控制，只有 4 帧直接执行联想记忆。

5. **15.0 秒，帧 150：顺序连接确实改变了读出。** 事件 `17295` 来自另一位置 `(6.28, 6.29)` 的静息动作，原始感觉得分只达本帧峰值的 88.0%，但顺序加成把它推为唯一回忆，实际肌肉全为 0。唯一一次预定数值干预只移除该帧的顺序加成，读出变成 16 个记忆混合的 `[0.4874, 0, 0.4653, 0.0221]`，肌肉向量变化量为 `0.6742`。没有执行这条假设动作或另跑后续轨迹，不能据此断言删除顺序就能解决导航。

6. **25.0 秒，帧 250：正在沿错误阶段的真实经历向前传播。** 当前在上口左侧 `(4.71, 6.93)`，事件 `35723` 却来自 bottom 回合 27 的 `(6.35, 1.72)`。那段训练已经从下口绕到墙右侧，而当前身体还在墙左侧。事件权重为 1，输出两侧前进。

7. **25.4 秒，帧 254：能具体追到造成前进的连接。** 当前在 `(4.98, 6.89)`；事件 `35727` 记录的是 `(6.49, 1.94)`，仍属于上述墙右侧阶段。186 条当前活动 PFC→事件连接贡献 `0.292900`，回忆视感反馈再加 `0.020264`，顺序输入再加 `0.119180`，最终得分 `0.432344`，归一化权重为 1。它输出 `[0.6, 0, 0.6, 0]`，身体在下一小段运动中从上口穿过中线。

9. **98.5 秒，帧 985：到目标没有纠正已经走错的通道。** 最终短段由持续探索的前进动作执行，98.54 秒进入红色目标。完整记录显示首次通道为 top，因此任务失败，也没有奖励。新音之后的全部 886 帧，规则群都保持 bottom。

帧 254 还可核对到单个细胞：PFC `91` 接收目标单元 `0`、规则单元 `1` 和两个 RGB 阈值受体 `3377/2795`。两个 RGB 值都是灰墙的 `0.35`，均满足其小于阈值的条件；四路输入合计 4，超过阈值 3.5。该细胞沿已有连接为事件 `35727` 贡献约 `0.001244`。其余 185 条活动连接共同形成上述 `0.292900`。JSON 保留每条活动连接的编号和归一化贡献，可继续逐条检查。

因此，本例首先暴露的是**感觉相似却位置、阶段不同的经历被接入当前回放**。错误经历的原始得分仍达到当前峰值的 86%，通过了 80% 的感觉支持门限；先后连接随后放大了这个错误起点。顺序本身确实来自实际经历，问题是当前该从哪段经历开始、何时应抑制或放弃它。局部肌肉混合、身体反射和探索影响了过程，但穿错口的关键帧执行的是单条记忆的前进动作。
