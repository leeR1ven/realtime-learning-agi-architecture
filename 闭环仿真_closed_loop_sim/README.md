这是关联神经元架构的**限定闭环原型**：一个身体在二维物理环境中自主推进，接收距离、颜色、接触疼痛与声音信号，边行动边更新连接，也能把学到的音调与动作关联、音调与口部输出关联保存下来。它用于验证感知、神经活动、肌肉、环境反馈和在线学习能否共同运行，尚未完成 AGI、双足机器人或自然语言系统。

本次新增代码都在 `闭环仿真_closed_loop_sim`。项目根目录原有神经模块未修改；这里引用原有类并创建新实例。根据用户最新要求，**无需查找或恢复旧 m8 模型**，保留从新同构分支分别训练、融合、继续学习的能力。

**启动与交互。** 双击 [启动仿真_launch_sim.cmd](启动仿真_launch_sim.cmd)。它使用项目已有的 `.venv` Python 打开本地窗口。也可在 PowerShell 中运行以下命令，以便看到启动错误：

```powershell
Set-Location -LiteralPath '.\闭环仿真_closed_loop_sim'
& '..\.venv\Scripts\python.exe' -X utf8 viewer.py
```

窗口打开后，身体会自动行动，正常情况下每秒执行 10 个仿真帧。灰色墙壁参与碰撞；彩色色标提供视觉刺激。射线和下方色块显示身体实际收到的五束距离/RGB 信号，右侧显示肌肉输出、疼痛、危险关联、神经活动及计算耗时。

- 点击“音调①～④”只给模拟听觉发送声音，持续 1 秒，不施加运动刺激或正强化。对应频率为 220、440、660、880 Hz。
- 在“现场教学”选择音调和配对动作，点击“配对教学 2 秒”。这 20 帧同时提供声音、运动神经刺激和正强化，身体仍经过相同的感知、学习与物理循环。
- 教学结束后点击“撤去教学，只发声音”，观察撤去动作刺激后的反应。必要时重复教学。把已经学会的音调改配另一个动作会产生旧新关联竞争，当前不保证一次教学就覆盖旧关联。
- 勾选“同时示范口部发出同一音调”再教学，可建立音调到口部输出的联结。日志会显示发出的音调，其 PCM 波形会在下一帧回到自身听觉。
- “暂停”暂停整个循环；“重新开始场景”重置身体位置、场景和短时活动，保留已学习的连接与经历。

当前声音是在仿真内部传递的 8 kHz PCM 数组，真实麦克风尚未接入。可勾选“播放音调到扬声器（仅展示）”（默认关闭），听到声音按钮、教学启动及实际脑口部输出对应的 0.1 秒短音。播放异步进行，不改变脑收到的 PCM 或下一帧自听；同时有多个口部音调时，日志与脑内波形保留全部，扬声器目前仅示意第一个。音调标签与动作名称只是界面说明，模型没有读取这些文字。

**哪些部分来自出生设置，哪些部分在学习。** 具体实现见 [brain.py](brain.py)、[neural.py](neural.py) 和 [world.py](world.py)。

| 部分 | 当前实现与边界 |
| --- | --- |
| 身体 | 二维推进身体，四路拮抗肌肉控制左右推进力，力和力矩改变运动；包含惯性、阻力、碰撞冲量与摩擦。没有腿、关节或平衡控制。 |
| 视觉/距离 | 五束射线直接测得距离和 RGB，经固定受体编码进入神经层。没有从摄像头像素学习视觉表征，也没有物体语义识别。 |
| 感觉编码 | 33 个通道，每通道 10 级，使用成对受体与固定相邻边界检测，共 660 个特征位置。固定出生编码让不同等级可区分；这一实现没有复现历史讨论中的稠密随机感觉隐藏层。 |
| 出生运动 | 静息、前进、后退、左转、右转五个动作，在出生时各示范一次，经原 `反向赫布网络` 建立命令到肌肉的连接；日常运行把这些连接作为固定本能。自主前进、颜色定向、触痛退缩等投射也是出生设置。另设出生本能区（`本能区_instinct.py`）：接触退缩、侧向滑脱、前方开度选边与痛觉哭喊等固定直接投射，不经前额叶、不参与赫布学习。 |
| 疼痛学习 | 真实碰撞产生疼痛，先前距离活动的短时痕迹与疼痛共同加强危险连接，使随后遇到相近障碍时的动作发生变化。接触类本能只在“已经接触”时触发、不预判，因此不会抢走碰撞学习的训练信号。学习前后的留出场景比较及清除危险连接的消融检验这一效果。 |
| 声音学习 | 对四个固定频带进行检测，学习声音到动作、声音到口部音调的可塑连接。可更换教学映射；当前能力属于音调条件关联。 |
| 前额联想与时间记忆 | 沿用原前额叶、记忆区与时间环的类和局部时序规则。PFC 与记忆输出确实进入动作驱动；时序学习的经验源使用实际前后感官和运动副本，避免把想象输出当成已经发生的教学证据。 |

每帧由 `Brain.step(...)` 执行同一个循环：感知、回忆、前额活动、动作竞争、肌肉输出及连接更新。正常窗口运行中的学习始终开启；教学只是增加外界刺激。前额活动设有动态抑制，记忆可以同时激活多个时刻，相关连接仍全部参与传播。运动端选择一个动作簇，再通过原反向赫布连接译成肌肉力；没有直接把行为标签写成身体坐标。

这也明确了当前与完整架构的距离：固定出生编码和五种运动本能简化了感觉与运动学习；用真实经验约束时序写入，尚未实现对所有内部想象经历的完整记录机制。时间环也会在转满后复用槽位，当前不是无限长期记忆系统。

**存档与继续生活。** 窗口启动时依次尝试加载以下文件：

1. `results\living_brain.npz`：你在窗口中持续交互的模型，优先加载。
2. `results\demo_brain.npz`：评估程序生成的教学/融合演示基线。
3. 两者均不可用时，从出生连接创建新模型；加载错误会写入 `results\viewer.log`。

手动“保存检查点”、每 5 分钟自动保存及正常关闭窗口，都会写入 `living_brain.npz`，随后打开窗口继续学习。保存内容包括连接、时间事件和必要的神经瞬态；**身体位置和完整世界状态不在脑存档中**，重新打开窗口会从新场景开始。重置场景不会把模型退回出生状态。

界面不会改写 `demo_brain.npz`。重新运行评估会生成新的演示与实验文件，但不改 `living_brain.npz`，所以已有生活存档仍会优先加载。需要回到演示基线时，先正常关闭窗口，再把生活存档另存一个备份名称；下次启动即可加载演示基线。

存档使用 [checkpoint.py](checkpoint.py) 的 JSON 元数据与 NumPy 数组，加载禁用 pickle。写入先在同目录创建临时文件，完成并刷新后再替换目标文件；失败写入保留原有效存档，界面记录错误并可继续运行。当前窗口保存是同步操作，保存帧可能暂时变慢；原子替换不等于断电情况下绝对零损失，未保存的最近经历仍可能丢失。

**复现实验与读取证据。** 本次结果摘要见 [验收结果_acceptance.md](验收结果_acceptance.md)。当前原始结果以 [evaluation.json](results/evaluation.json) 为准，轨迹与神经摘要在 [trace.json](results/trace.json)。报告记录实际帧数、仿真时长、墙钟计算时间及 P50/P95/P99 延迟；请检查 `performance.frames`，不要把较短检查的数字当成长时间运行结果。

在 PowerShell 中依次执行：

```powershell
Set-Location -LiteralPath '.\闭环仿真_closed_loop_sim'
& '..\.venv\Scripts\python.exe' -X utf8 neural.py
& '..\.venv\Scripts\python.exe' -X utf8 _check_checkpoint.py
& '..\.venv\Scripts\python.exe' -X utf8 viewer.py --smoke-test
& '..\.venv\Scripts\python.exe' -X utf8 evaluate.py --soak-frames 10000
```

前三项检查固定编码/运动译码、存档完整性以及不打开窗口的真实交互接口。最后一项重新教学并执行完整行为评估，随后运行指定帧数的持续学习闭环。它会更新 `results` 下的实验模型、演示模型和报告；正式结果完成后终端给出 `passed` 与每项 `checks`。10000 帧对应 1000 秒仿真时间，程序可以加速计算，不能据此把仿真时间称为实际等待时间。

评估包含以下可检查的因果证据：

- 先经历碰撞，再对不同位置、尺寸和颜色的障碍进行留出比较；单独检查关闭新增学习后的经验迁移，以及清除危险连接后的表现。
- 更换音调与动作的教学映射，再撤去运动刺激和强化，并改变音量、相位、加入噪声。分别屏蔽前额通路、时间记忆通路，及同时断开两者，检查已学关联依赖哪些连接。
- 两个新分支各学不同音调子集，融合后分别检查两部分技能与时间事件数量，再继续碰撞学习。
- 存档恢复后用相同观察序列检查动作、口部输出与新增权重；断开原反向赫布运动连接后检查肌肉是否停止发力。
- 持续运行同时计入脑、在线学习和物理计算，检查有限值、延迟与末段移动距离。
- 先想后动（冻结推演）：已学危险前动作门被压住，冻结帧静息、不出声、不写经历，念头沿前额叶内部联想链推进；回放到“绕行且无疼”后继、或超过冻结上限（冲动放行）后解冻并绕行，全程不碰撞。

消融实验中的关闭学习/通路开关仅用于定位行为原因，交互模式仍是统一的持续学习循环。通过这些有限任务不能证明所有场景泛化，也不能把每个动作都归因于学习，因为出生本能本来就参与行为。

**多个分支训练与融合。** [evaluate.py](evaluate.py) 已给出两个同构新分支分别教学、融合和续学的完整示例。分支必须使用一致的特征布局和出生连接。新示例验证的是互补的音调经验，尚未验证任意冲突经验、大规模多分支或自然语言知识融合。

融合的数组契约如下：

| 数据 | 处理方法 |
| --- | --- |
| `fixed_*` | 形状、类型、数值必须完全一致，原样保留。 |
| `plastic_*` | 包含前额联想、去抑制、听觉、发声和危险权重，按父模型数逐元素平均。 |
| `mem_event_*` / `mem_edge_*` | 所有时间事件和双向连接完整拼接、不去重。每个父模型的事件编号分别偏移，`next` 链及断链标记保留；每事件强度除以父模型数，边权不重复缩放。 |
| `state_*` | 单模型保存/恢复保持原状态；融合时清零短时状态，再使用出生默认值，新经历从独立时间环开始。 |

融合还验证 `schema_version`、`birth_hash`、`feature_schema` 与配置，记录父文件路径和 SHA-256。输出路径不得覆盖任一父模型。原分支保留，可独立继续学习。示例 API：

```python
from checkpoint import merge_checkpoints
from brain import Brain

merge_checkpoints(
    ["results/branch_a.npz", "results/branch_b.npz"],
    "results/fused_manual.npz",
)
brain = Brain.load("results/fused_manual.npz")
# 接下来照常调用 brain.step(observation, waveform)，继续感知与学习。
```

当前示例的两个分支在评估中依次教学，用于验证融合机制；没有启动多卡或多个训练进程。并发训练调度、长期检查点传输和大规模融合仍属于后续工程。

**本地硬件与下一步。** 当前设备为 i5-12600KF（10 核、16 线程）、16 GB 内存、RTX 3070 Ti 8 GB。本原型主要使用 NumPy 在 CPU 上运行，GPU 并未承担模型计算；现阶段无需租卡。以最新报告的完整闭环耗时判断当前规模是否满足 100 ms 帧预算。这个小模型的表现不能推算更大模型内存上限，也不能证明租 A800 会获得多少加速。

用户已明确最终目标是仿脑的持续认知与交流。下面的工作优先级以此为准；运动与音调配对只检验了基础接口。新增的前额叶因果检查和独立候选机制实验见 [认知实验](../认知实验_cognition_experiments/README.md)。

1. 先检验持续的前额叶活动是否真正驱动决策。任务要求当前外界信号相同、先前上下文不同而答案相反；分别检查内部状态、学到的连接和即时关联通路，不能用一个总开关混在一起归因。
2. 比较前额叶容量、跨通道连接、循环连接和状态保持机制，测量延迟、干扰与认知负荷下的表现。候选机制实验必须注明与原规则的差异，不能把新增机制的成绩当成原架构未经修改的成绩。
3. 优先推进物体与词语绑定、交流中的纠错、指代和组合要求。区别出生本能、教学获得的单项联结，以及可迁移的关系知识；测试首次作答、陌生组合和旧知识保持。
4. 让内部预测经行动和真实结果检验，区分想象与已经发生的经历；扩展长期学习、冲突教学、回放与巩固实验。完成这些能力不以先实现双足行走为前提。
5. 随认知实验同步做受控扩容与同构分支训练，测试融合后知识合作、冲突和遗忘；以实际的计算、内存、显存和带宽瓶颈决定租用硬件。
